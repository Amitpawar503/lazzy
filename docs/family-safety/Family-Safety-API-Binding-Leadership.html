Leadership summary

Family Safety — Orchestration API Binding

Each app-facing (upstream) API — merged by endpoint — mapped to the two downstream systems, Network and Whalebone, with the full request on both sides. Enum values that hit the same downstream are joined with /. Downstream paths are the real Network (/api/v1/…) and Whalebone (/management/…, /events/…) endpoints. Base /family-safety/v1 · MSISDN = deviceID = subscriptionID · circleId = familyId.
