Family Safety — Orchestration API Binding

Each upstream API — merged by endpoint — mapped to Network and Whalebone, now with a Downstream enum column and the full BEFE surface (B01–B74) added below the core. Network event APIs are consolidated into one /safety-event resource; parental controls are one API with resource as a query-param enum. Enum values that hit the same downstream are joined with /. Base /family-safety/v1 · MSISDN = deviceID = subscriptionID · circleId = familyId.
